Cách dùng

OpenAI-compatible: /v1/chat/completions, /v1/models (Cline / Continue / aider / OpenAI SDK) — và Anthropic /v1/messages nên Claude Code trỏ thẳng vào được.

Claude Code → trỏ vào server này:

macOS / Linux (bash · zsh):
export ANTHROPIC_BASE_URL="{{ base_url[:-3] }}"   # bỏ /v1 ở cuối
export ANTHROPIC_AUTH_TOKEN="<API key ở trên>"
export ANTHROPIC_MODEL="qwen3-coder-30b"          # = model id của server
claude
Windows — PowerShell:
$env:ANTHROPIC_BASE_URL  = "{{ base_url[:-3] }}"   # bỏ /v1 ở cuối
$env:ANTHROPIC_AUTH_TOKEN = "<API key ở trên>"
$env:ANTHROPIC_MODEL      = "qwen3-coder-30b"
claude
Windows — CMD (cmd.exe):
set ANTHROPIC_BASE_URL={{ base_url[:-3] }}
set ANTHROPIC_AUTH_TOKEN=<API key ở trên>
set ANTHROPIC_MODEL=qwen3-coder-30b
claude
Đặt vĩnh viễn (khỏi gõ lại mỗi lần mở terminal)
Thêm khối env vào file cấu hình của Claude Code — ~/.claude/settings.json (Windows: C:\Users\<tên>\.claude\settings.json): 
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{ base_url[:-3] }}",
    "ANTHROPIC_AUTH_TOKEN": "<API key ở trên>",
    "ANTHROPIC_MODEL": "qwen3-coder-30b"
  }
}
Cách này áp dụng cho mọi terminal, không phụ thuộc OS.

Khôi phục Claude Code về mặc định (Anthropic):

Xoá 3 biến ở trên để Claude Code quay về dùng api.anthropic.com với tài khoản của bạn.

macOS / Linux:
unset ANTHROPIC_BASE_URL ANTHROPIC_AUTH_TOKEN ANTHROPIC_MODEL
claude            # rồi /login để đăng nhập lại tài khoản Anthropic
Windows — PowerShell:
Remove-Item Env:ANTHROPIC_BASE_URL,Env:ANTHROPIC_AUTH_TOKEN,Env:ANTHROPIC_MODEL
claude            # rồi /login
Windows — CMD:
set ANTHROPIC_BASE_URL=
set ANTHROPIC_AUTH_TOKEN=
set ANTHROPIC_MODEL=
claude            :: rồi /login

Nếu đã đặt vĩnh viễn: xoá khối env trong ~/.claude/settings.json (hoặc xoá luôn file). Lệnh set …= / unset chỉ tác dụng trong cửa sổ terminal hiện tại — mở cửa sổ mới là đã sạch.

OpenAI SDK / Cline / aider:

from openai import OpenAI
client = OpenAI(base_url="{{ base_url }}", api_key="<API key>")
r = client.chat.completions.create(
    model="qwen3-coder-30b",   # = model id của server
    messages=[{"role": "user", "content": "Viết quicksort bằng Python"}],
    stream=True,
)
for chunk in r:
    print(chunk.choices[0].delta.content or "", end="")
